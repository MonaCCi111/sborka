## Ячейка 1. Что значит подобрать функцию по точкам

Есть таблица измерений. Столбец $x_i$ хранит входное значение, столбец $y_i$ – измеренное. Когда подставляешь $x_i$ в подобранную формулу, получаешь расчётное значение $\hat y_i$. Значок над $y$ помогает отличать расчёт от измерения.

Для точки $(2,5)$ формула $y=2x$ даёт $\hat y=4$. Отклонение равно $4-5=-1$, квадрат отклонения равен $1$. Чтобы оценить всю формулу, складываем квадраты таких отклонений по всем точкам. Эту сумму обозначим $L$.

$$
L=\sum_{i=1}^{n}(\hat y_i-y_i)^2.
$$

Квадраты нужны, чтобы промахи вверх и вниз складывались. Например, отклонения $-1$ и $+1$ в сумме дают ноль, а сумма их квадратов равна $2$. Метод наименьших квадратов, или МНК, подбирает коэффициенты так, чтобы $L$ было как можно меньше на данных, по которым строим модель. Для двух моделей с логарифмами ниже расчёт коэффициентов проходит в преобразованных координатах.

**Мини-задание 1 · Посчитай отклонения**

Есть точки $(1,3)$ и $(2,3)$. Найди $L$ для формулы $y=2x$.

> [!check]- Проверить ответ
> Расчётные значения – $2$ и $4$. Отклонения – $-1$ и $+1$. Получается $L=1+1=2$.

## Ячейка 2. Прямая $y=ax+b$

$a$ задаёт наклон. При увеличении $x$ на единицу значение $y$ меняется на $a$. $b$ равно значению прямой при $x=0$.

Для прямой $\hat y_i=ax_i+b$, поэтому $L(a,b)=\sum_i(ax_i+b-y_i)^2$. Берём производные по $a$ и $b$, приравниваем их к нулю и собираем слагаемые. Получается система для двух неизвестных:

$$
\begin{cases}
a\sum x_i^2+b\sum x_i=\sum x_i y_i,\\
a\sum x_i+bn=\sum y_i.
\end{cases}
$$

$\sum x_i^2$ – сумма квадратов отдельных значений $x$. $\sum x_i y_i$ – сумма произведений $x$ и $y$ из одной строки. Запись $\sum$ в этой системе всегда означает сумму по всем точкам.

**Мини-задание 2 · Собери систему**

Для точек $(1,3)$ и $(2,5)$ найди четыре суммы из системы и реши её.

> [!check]- Проверить ответ
> $\sum x_i=3$, $\sum x_i^2=5$, $\sum y_i=8$, $\sum x_i y_i=13$. Система $5a+3b=13$, $3a+2b=8$ даёт $a=2$ и $b=1$.

## Ячейка 3. Степенная и показательная функции

Обе функции можно привести к прямой с помощью натурального логарифма $\ln$. В Python этому соответствует `np.log`, а обратному преобразованию $e^b$ – `np.exp(b)`.

**Степенная функция.** В $y=\beta x^a$ переменная $x$ стоит в основании степени. Логарифмируем $x$ и $y$, поэтому для расчёта прямой берём $X=\ln x$ и $Y=\ln y$.

$$
\ln y = a\ln x+\ln\beta.
$$

**Показательная функция.** В $y=\beta e^{ax}$ переменная $x$ стоит в показателе степени. Логарифмируем $y$, поэтому берём $X=x$ и $Y=\ln y$.

$$
\ln y=ax+\ln\beta.
$$

В обоих случаях решаем систему из ячейки 2 для прямой $Y=aX+b$. Полученный $a$ сразу идёт в итоговую формулу, а из $b=\ln\beta$ восстанавливаем $\beta=e^b$. Для степенной модели нужны $x>0$ и $y>0$, для показательной – $y>0$.

При расчёте этих коэффициентов МНК минимизирует квадраты отклонений по $\ln y$. Для сравнения всех четырёх функций вернись к исходному $y$ и посчитай одну и ту же сумму $\sum_i(\hat y_i-y_i)^2$.

**Мини-задание 3 · Вернись из логарифмов**

После замены $X=x$, $Y=\ln y$ получилась прямая $Y=0{,}5X+\ln 2$. Какая это модель и чему равно $\hat y$ при $x=2$?

> [!check]- Проверить ответ
> Показательная. $\beta=e^{\ln 2}=2$, поэтому $\hat y=2e^{0{,}5x}$. При $x=2$ получаем $2e\approx5{,}4366$.

## Ячейка 4. Квадратичная функция $y=ax^2+bx+c$

На графике это парабола. В расчёте добавляется третья неизвестная, $c$. Подставляем $\hat y_i=ax_i^2+bx_i+c$ в формулу для $L$ и приравниваем к нулю три производные – по $a$, $b$ и $c$.

$$
\begin{cases}
a\sum x_i^4+b\sum x_i^3+c\sum x_i^2=\sum x_i^2y_i,\\
a\sum x_i^3+b\sum x_i^2+c\sum x_i=\sum x_i y_i,\\
a\sum x_i^2+b\sum x_i+cn=\sum y_i.
\end{cases}
$$

Степени берём для каждого $x_i$ отдельно. Например, для точек $(1,3)$, $(2,5)$ правая часть первой строки равна $1^2\cdot3+2^2\cdot5=23$.

## Ячейка 5. Как сравнить формулы

Подставь одни и те же исходные $x_i$ в каждую из четырёх функций. Сравни полученные $\hat y_i$ с исходными $y_i$ и вычисли $L$ для каждой функции. Меньшее $L$ означает, что модель точнее описала эту таблицу по критерию задания. График помогает увидеть, на каких участках каждая кривая отклоняется от точек.

**Мини-задание 4 · Выбери модель**

Измеренные значения $y$ равны $2$ и $5$. Первая формула дала $2$ и $7$. Вторая дала $3$ и $4$. Какая лучше по $L$?

> [!check]- Проверить ответ
> Для первой $L=0^2+2^2=4$. Для второй $L=1^2+(-1)^2=2$. По этому критерию лучше вторая.

## Разбор типового примера

### Ячейка 6. Вводим данные

В примере из задания шесть точек. Первый элемент массива `x` соответствует первому элементу `y`, второй – второму и так далее.

| $x$ | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y$ | 1,0 | 1,5 | 3,0 | 4,5 | 7,0 | 8,5 |

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.array([1, 2, 3, 4, 5, 6], dtype=float)
y = np.array([1, 1.5, 3, 4.5, 7, 8.5], dtype=float)
n = x.size
```

### Ячейка 7. Подбираем прямую

Для этих данных $\sum x_i=21$, $\sum x_i^2=91$, $\sum y_i=25{,}5$ и $\sum x_i y_i=117$. Например, последняя сумма начинается с $1\cdot1+2\cdot1{,}5+3\cdot3$. После подстановки получаем систему.

$$
\begin{cases}
91a+21b=117,\\
21a+6b=25{,}5.
\end{cases}
$$

В `matrix` записываем коэффициенты слева, в `right` – числа справа. `np.linalg.solve` возвращает $a$ и $b$ в порядке столбцов матрицы. Функцию `fit_line` используем ещё два раза, когда перейдём к $X$ и $Y$.

```python
def fit_line(X, Y):
    sum_x = np.sum(X)
    matrix = [
        [np.sum(X**2), sum_x],
        [sum_x, X.size],
    ]
    right = [np.sum(X * Y), np.sum(Y)]
    return np.linalg.solve(matrix, right)

a_line, b_line = fit_line(x, y)
print(f"a = {a_line:.4f}, b = {b_line:.4f}")

a_line = round(a_line, 2)
b_line = round(b_line, 2)
```

Получаем $a\approx1{,}5857$, $b=-1{,}3000$. После округления формула принимает вид $\hat y=1{,}59x-1{,}30$. При $x=2$ модель даёт $1{,}88$. Измеренное значение равно $1{,}50$, вклад этой точки в $L$ равен $0{,}38^2=0{,}1444$.

### Ячейка 8. Подбираем степенную и показательную функции

Для степенной модели первая преобразованная пара равна $(\ln 1,\ln 1)=(0,0)$, а вторая – $(\ln 2,\ln 1{,}5)\approx(0{,}6931;\ 0{,}4055)$. Для показательной в этих же парах используем исходные $x$, то есть $1$ и $2$. Массив `log_y` подходит для обеих моделей.

```python
log_y = np.log(y)

a_power, b_power = fit_line(np.log(x), log_y)
beta_power = np.exp(b_power)
print(f"Степенная: a = {a_power:.4f}, b = {b_power:.4f}, beta = {beta_power:.4f}")

a_exp, b_exp = fit_line(x, log_y)
beta_exp = np.exp(b_exp)
print(f"Показательная: a = {a_exp:.4f}, b = {b_exp:.4f}, beta = {beta_exp:.4f}")

a_power = round(a_power, 2)
beta_power = round(beta_power, 2)
a_exp = round(a_exp, 2)
beta_exp = round(beta_exp, 2)
```

Для степенной модели получаем $a\approx1{,}2573$, $b\approx-0{,}1963$ и $\beta\approx0{,}8217$. Итоговая формула – $\hat y=0{,}82x^{1{,}26}$.

Для показательной модели получаем $a\approx0{,}4493$, $b\approx-0{,}3904$ и $\beta\approx0{,}6768$. Итоговая формула – $\hat y=0{,}68e^{0{,}45x}$. Значение $\beta$ вычисляем из $b$ до его округления.

### Ячейка 9. Подбираем параболу

Из тех же шести точек получаем $\sum x_i^3=441$, $\sum x_i^4=2275$ и $\sum x_i^2 y_i=587$. Эти суммы заполняют первую строку системы вместе с уже знакомым числом $\sum x_i^2=91$. Получается $2275a+441b+91c=587$.

```python
sum_x = np.sum(x)
sum_x2 = np.sum(x**2)
sum_x3 = np.sum(x**3)
sum_x4 = np.sum(x**4)

matrix = [
    [sum_x4, sum_x3, sum_x2],
    [sum_x3, sum_x2, sum_x],
    [sum_x2, sum_x, n],
]
right = [np.sum(x**2 * y), np.sum(x * y), np.sum(y)]

a_quad, b_quad, c_quad = np.linalg.solve(matrix, right)
print(f"a = {a_quad:.4f}, b = {b_quad:.4f}, c = {c_quad:.4f}")

a_quad = round(a_quad, 2)
b_quad = round(b_quad, 2)
c_quad = round(c_quad, 2)
```

Получаем $a\approx0{,}1607$, $b\approx0{,}4607$ и $c=0{,}2000$. Итоговая формула – $\hat y=0{,}16x^2+0{,}46x+0{,}20$.

### Ячейка 10. Считаем погрешности

Для сравнения используем записанные выше формулы с коэффициентами до сотых. В этой ячейке округляем расчётные значения $\hat y_i$ до четырёх знаков после запятой и по ним считаем $L$. Например, для параболы при $x=2$ выходит $0{,}16\cdot4+0{,}46\cdot2+0{,}20=1{,}76$. Вклад точки в $L$ равен $(1{,}76-1{,}50)^2=0{,}0676$.

```python
predictions = {
    "Линейная": a_line * x + b_line,
    "Степенная": beta_power * x**a_power,
    "Показательная": beta_exp * np.exp(a_exp * x),
    "Квадратичная": a_quad * x**2 + b_quad * x + c_quad,
}

errors = {}
for name, predicted_y in predictions.items():
    predicted_y = np.round(predicted_y, 4)
    errors[name] = np.sum((predicted_y - y)**2)
    print(f"{name}: L = {errors[name]:.4f}")

best = min(errors, key=errors.get)
print(f"Минимальная погрешность: {best.lower()}")
```

| Модель | $L$ |
| --- | ---: |
| Линейная | 1,3731 |
| Степенная | 1,3923 |
| Показательная | 3,2447 |
| Квадратичная | **0,4088** |

В этом примере квадратичная функция дала наименьшую сумму квадратов отклонений. У прямой и степенной функции ошибки близки, поэтому по одному виду графиков их удобнее проверить числами.

### Ячейка 11. Строим общий график

Для каждой кривой берём 300 значений $x$ между первой и последней границами данных. Исходные шесть наблюдений наносим отдельно с помощью `scatter`. Суммы ошибок из предыдущей ячейки рассчитаны по шести наблюдениям.

```python
x_grid = np.linspace(x.min(), x.max(), 300)

plt.figure(figsize=(9, 5))
plt.plot(x_grid, a_line * x_grid + b_line, label="Линейная")
plt.plot(x_grid, beta_power * x_grid**a_power, label="Степенная")
plt.plot(x_grid, beta_exp * np.exp(a_exp * x_grid), label="Показательная")
plt.plot(x_grid, a_quad * x_grid**2 + b_quad * x_grid + c_quad, label="Квадратичная")
plt.scatter(x, y, color="black", label="Измерения", zorder=3)
plt.xlabel("x")
plt.ylabel("y")
plt.legend()
plt.grid(alpha=0.25)
plt.tight_layout()
plt.show()
```
